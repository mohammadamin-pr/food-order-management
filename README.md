# Food Order Management System

A Python program that takes food orders from the user, calculates the total price, delivery fee, and discount, and displays the final order information.

## Technologies

- Python

## Features

- Getting the customer's name
- Displaying a food menu
- Choosing food from the menu
- Showing the food price
- Confirming or changing the selected food
- Ordering multiple foods
- Calculating the total food price
- Checking VIP customer status
- Calculating delivery fees
- Applying discount codes
- Displaying the final order information
